# HelloTasks

**A minimal, lightweight, always-on-top task manager for Windows.**

HelloTasks helps you stay organized and focused with a clean, distraction-free interface. Built with **Python and PySide6**, it works completely offline and stores your tasks locally.

[![Windows](https://img.shields.io/badge/Platform-Windows-blue)](https://github.com/itsrajmaurya/HelloTasks)
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)
[![Python](https://img.shields.io/badge/Python-3.x-yellow)](https://python.org)

## Features

- Clean, minimal UI with light and dark themes
- Always-on-top floating task widget
- Add tasks with tags and notes
- Mark tasks completed and restore them anytime
- Completed tasks and activity history
- Automatic local storage using SQLite
- No login, internet, or cloud required
- Custom Windows EXE icon support

## Download

**[Download HelloTasks for Windows](https://github.com/itsrajmaurya/HelloTasks/releases/latest)**

Download `HelloTasks.exe` from the latest release.

## Run from Source

```bash
git clone https://github.com/itsrajmaurya/HelloTasks.git
cd HelloTasks
pip install -r requirements.txt
python main.py
```

## Build EXE

Run `build_windows.bat` to generate `dist/HelloTasks.exe`.
